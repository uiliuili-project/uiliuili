# S3 存储

> [English](../s3.md)

uiliuili 只实现一种云存储驱动：S3 API。它兼容 AWS S3 以及 Cloudflare R2、腾讯云 COS、MinIO 等 S3 兼容端点。

## 配置

在安装器或管理后台设置中填写：

- endpoint（AWS 可留空）
- region
- bucket
- access key ID
- secret access key
- path-style 开关
- 可选的公开访问基础 URL 或 CDN 域名
- 对象前缀

安装器会执行 Put/Get/Delete 测试。

## Bucket CORS

浏览器直传要求 bucket 配置 CORS：

```json
[
  {
    "AllowedOrigins": ["https://video.example.com"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

## 权限

Access Key 需要在配置的前缀上具备 `s3:PutObject`、`s3:GetObject`、
`s3:DeleteObject`、`s3:ListBucket` 以及分片上传权限。

## 说明

- 公开视频可以使用 CDN 或公开基础 URL。
- 私有和未列出视频使用短时效签名 URL。
- 切换存储驱动不会迁移已有文件。切换前请先迁移文件，或为旧资源保留原驱动。
- 部署在其他机器上的 worker 必须使用 S3 存储；使用本地存储时需要共享卷。
