# S3 storage

uiliuili implements one cloud storage driver: the S3 API. It works with AWS S3
and compatible endpoints such as Cloudflare R2, Tencent COS, and MinIO.

## Configuration

In the installer or admin settings, provide:

- endpoint (leave blank for AWS)
- region
- bucket
- access key ID
- secret access key
- path-style toggle
- optional public base URL or CDN domain
- object prefix

The installer performs a Put/Get/Delete test.

## Bucket CORS

Direct browser uploads require CORS on the bucket:

```json
[
  {
    "AllowedOrigins": ["https://video.example.com"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

## Permissions

The access key needs `s3:PutObject`, `s3:GetObject`, `s3:DeleteObject`,
`s3:ListBucket`, and multipart upload permissions on the configured prefix.

## Notes

- Public videos may use a CDN/public base URL.
- Private and unlisted videos use short-lived signed URLs.
- Switching storage drivers does not move existing files. Migrate them before
  switching, or keep the old driver for existing assets.
- Workers deployed on other machines require S3 storage; local storage requires
  a shared volume.
